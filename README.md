# Aqsa Anwar — AI Quality Engineer Portfolio

This is a plain HTML, CSS, and JavaScript portfolio. No build command is required.

## Open in VS Code

1. Open VS Code.
2. Select **File → Open Folder**.
3. Select this `aqsa-ai-qa-portfolio` folder.
4. Open `index.html` in a browser, or use the VS Code **Live Server** extension for live preview.

## Edit content

- Each page has its own `.html` file.
- Shared visual styling is in `styles.css`.
- Mobile menu behaviour is in `script.js`.
- Replace placeholder text and `href="#"` links before publishing.
- Update `your@email.com` in `contact.html`.

## Publish with GitHub and Vercel

Install [Git](https://git-scm.com/downloads) and sign in to GitHub first. Then, from the VS Code terminal inside this folder:

```powershell
git init
git add .
git commit -m "Initial AI QA portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/aqsa-ai-qa-portfolio.git
git push -u origin main
```

Next, visit [vercel.com/new](https://vercel.com/new), sign in with GitHub, import the `aqsa-ai-qa-portfolio` repository, and click **Deploy**. Vercel will recognize this as a static site automatically.

After deployment, add your `https://...vercel.app` URL to your resume.
